# Pinned transitive dependency versions for the ingstr image.
#
# WHY THIS FILE EXISTS. pyproject.toml declares ranges, so the same source
# built on two days produced two different images — which is how v0.1.1 ended
# up with a numba that needs a writable cache directory while v0.1.0 did not,
# and how every PDF in the ARC restore failed on 2026-11-13 from a source
# change nobody made. A constraints file makes the build reproducible without
# freezing the ranges in pyproject.toml, which stay as the compatibility
# statement they are.
#
# HOW TO REGENERATE, when a dependency is deliberately moved:
#
#   python3 -m venv /tmp/lockenv
#   /tmp/lockenv/bin/pip install --upgrade pip
#   /tmp/lockenv/bin/pip install .
#   /tmp/lockenv/bin/pip freeze --exclude-editable | grep -v '^ingstr' \
#     > constraints.txt   # then put this header back
#
# Resolve it on Linux with the image's Python (3.12) so the result matches
# what the build will install. Bump deliberately, with a release-notes line,
# and never silently.
#

# running image has: unstructured 0.27.37, numba 0.68.1.
